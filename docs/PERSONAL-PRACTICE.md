# 中文與個人答案練習

面試題庫預設顯示中文，支援英文／中英對照、30／60 秒目標、隱藏答案試說、口說筆記及練習進度。秒數為練習目標，實際請依語速調整。

每題公開回答是原創示範，不代表官方標準答案，也不宣稱一般行為題的示範是使用者真實經歷。

## 個人答案

在「面試」→「我的個人答案」選擇 JSON 檔，匯入後相關題目預設顯示「我的版本」，也可以切換通用示範。

- 檔案僅在瀏覽器讀取，儲存在此網站來源的 localStorage，不上傳伺服器或 GitHub。
- 手機、電腦、不同瀏覽器及本機預覽不會同步，需分別匯入。清除網站資料會移除答案。
- 重新匯入會取代舊個人答案，請保留原檔作備份；筆記匯出與答案檔為不同內容。
- 共用裝置使用後，可選「移除此瀏覽器的個人答案」，再次確認才移除，筆記與練習紀錄保留。
- 未通過格式驗證或超過 250 KB 的檔案不會取代現有資料。
- 個人檔不要加入公開 repository。回答內容應由本人確認，不可將朋友的自傳或未證實的事蹟寫成自己經歷。

## 格式

版本為 `1`，`answers` 以既有题目 id 為 key。每題必須提供非空字串 `zh_30`、`zh_60`、`en_30`、`en_60`、`coaching`、`follow_up`、`basis`，各欄最多 6000 字元。匯入僅保留這些欄位，以純文字呈現，不執行 HTML。

網站不會把通用答案的官方來源視為個人事蹟的驗證；個人稿另列整理依據，並提醒使用者確認。
